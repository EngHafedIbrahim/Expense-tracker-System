# Expense Tracker

A web-based expense tracking application built with PHP and MySQL. This application allows users to track their expenses, categorize them, view reports, and manage their budget.

## Features

- User registration and login
- Add, edit, and delete expenses
- Categorize expenses
- View dashboard with expense summaries
- Generate reports
- Profile management

## Installation

1. Install XAMPP or a similar web server with PHP and MySQL support.
2. Clone or download this repository to your web server's document root (e.g., `htdocs` in XAMPP).
3. Import the `expense_tracker_db.sql` file into your MySQL database.
4. Update the database configuration in `includes/config.php` if necessary.
5. Start your web server and navigate to the application in your browser.

## Usage

1. Register a new account or log in with existing credentials.
2. Add expenses using the expenses page.
3. View your dashboard for summaries.
4. Generate reports to analyze your spending.

## Technologies Used

- PHP
- MySQL
- HTML/CSS/JavaScript
